# 運算符

## 特殊符號

- `#` // 引入模塊
- `@` // 導出模塊
- `->` // 類型轉換
- <code>&lt;-</code> // for i <code>{'<-'}</code> [1, 2, 3] 替代in
- `..` // 父類
- `.` // 類自身
- `?` // 空 替代nil
- `!` // 假，錯誤 替代false
- `!!` // 真，正確 替代true
- `!{}` // 循環
- `*` // 繼續 替代continue
- `**` // 中斷 替代break
- `...` // 返回語句，终止函数 替代return

## 算術運算符

- `+` // 加法
- `-` // 減法
- `*` // 乘法
- `/` // 除法

## 比較運算符

- `==` // 等於
- `!=` // 不等於
- <code>&lt;</code> // 小於
- `>` // 大於
- <code>&lt;=</code> // 小於等於
- `>=` // 大於等於

## 邏輯運算符

- `&&` // 邏輯與
- `||` // 邏輯或
- `!` // 邏輯非
