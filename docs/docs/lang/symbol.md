# 運算符

## 特殊符號

- `#` // 引入模塊
- `@` // 導出模塊
- `->` // match arm 與 if/else 分支（如 `cond -> body`）
- `:` // match 表達式（如 `x: { ... }`）
- `!!` // 無限循環（`!! { }`）
- `<-` // 範圍遍歷（如 `i <- [a..b]: { }`）
- `..` // 父類
- `.` // 類自身
- `?` // option 類型前綴（如 `?i64`、`?str`）
- `!` // 假，錯誤 替代false（規劃中，暫不替代）
- `!!` // 真，正確 替代true（規劃中，暫不替代）
- `!{}` // 循環
- `*` // 中斷 替代break（規劃中，暫不替代）
- `**` // 跳過本輪 替代continue（規劃中，暫不替代）
- `...` // 返回語句，终止函数 替代return（規劃中，暫不替代）
- `run` // 啟動異步線程
- `awy` // 等待異步線程完成

## 算術運算符

- `+` // 加法
- `-` // 減法（也可用於字串拼接）
- `*` // 乘法（也可用於字串重複）
- `/` // 除法

## 比較運算符

- `==` // 等於
- `!=` // 不等於
- <code>&lt;</code> // 小於
- `>` // 大於
- <code>&lt;=</code> // 小於等於
- `>=` // 大於等於

## 邏輯運算符

- `&&` // 邏輯與
- `||` // 邏輯或（也可用於 match 分支組合，如 `nil || err -> body`）
- `!` // 邏輯非

## 位運算符

- `&` // 按位與
- `|` // 按位或
- `^` // 按位異或
- `~` // 按位取反
- <code>&lt;&lt;</code> // 左移
- `>>` // 右移

## 賦值運算符

- `=` // 賦值
- `+=` // 加賦值
- `-=` // 減賦值
- `*=` // 乘賦值
- `/=` // 除賦值
- `%=` // 模賦值
- `&=` // 位與賦值
- `|=` // 位或賦值
- `^=` // 位異或賦值
- <code>&lt;&lt;=</code> // 左移賦值
- `>>=` // 右移賦值

## 其他

- `?` // 三元運算符（如 `c = flag ? 1 : 2`）
- `as` // 類型轉換（如 `y = x as i64`）
- `..` // 切片範圍（如 `arr[1..3]`、`arr[1..]`、`arr[..3]`）
