# Операторы

## Специальные символы

- `#` ; импорт модуля
- `@` ; экспорт модуля
- `->` ; ветка match и ветка if/else (например, `cond -> body`)
- `:` ; выражение match (например, `x: { ... }`)
- `{ } (true)` ; бесконечный цикл (суффиксная форма, устаревшая запись); префиксная форма `!! { }` / `true { }` эквивалентна и является новой по умолчанию (выводится `no fmt`)
- `<-` ; перебор диапазона (например, `i <- [a..b]: { }`)
- `..` ; родительский класс / оператор диапазона (например, `[a..b)`)
- `.` ; сам класс (⚠️ в границах интервала используйте `self.method`, а не `.method`, чтобы избежать визуальной неоднозначности из трёх точек подряд)
- `?` ; префикс типа option (например, `?i64`, `?str`)
- `(cond) { }` ; условный цикл (префиксная форма, новая по умолчанию; эквивалентна суффиксной `{ } (cond)`)
- `N * { }` ; цикл с заданным числом повторов (префиксная форма, новая по умолчанию; эквивалентна суффиксной `{ } * N`; при N ≤ 0 пропускается)
- `!` ; ложь (false); также префикс цикла «никогда не выполняется» (`! { }` не выполняется никогда)
- `!!` ; истина (true); также префикс цикла «всегда выполняется» (`!! { }` — бесконечный цикл)
- `{ } ()` ; не выполняется (пустые скобки означают false; суффиксная форма, устаревшая запись); префиксные `! { }` / `false { }` / `() { }` эквивалентны и являются новой формой по умолчанию
- `*` ; пропустить текущую итерацию — заменяет continue (принимается парсером, но пока не рекомендуется — используйте ключевое слово)
- `**` ; прервать — заменяет break (принимается парсером, но пока не рекомендуется — используйте ключевое слово)
- `***` ; оператор возврата, завершает функцию — заменяет return (планируется, пока не рекомендуется — используйте ключевое слово)
- `awy { }` ; группа сопрограмм, в конце группы ожидаются все задачи `co`
- `co` ; «бесцветный» async-spawn, допустим только внутри группы `awy { }`

## Арифметические операторы

- `+` ; сложение
- `-` ; вычитание (также используется для конкатенации строк)
- `*` ; умножение (также используется для повторения строк)
- `/` ; деление

## Операторы сравнения

- `==` ; равно (для `str` — настоящее сравнение строк, многосимвольные строки допустимы)
- `!=` ; не равно (аналогично)
- <code>&lt;</code> ; меньше
- `>` ; больше
- <code>&lt;=</code> ; меньше или равно
- `>=` ; больше или равно

:::warning Операторы отношения (<code>&lt;</code> `>` <code>&lt;=</code> `>=`) не имеют семантики лексикографического сравнения строк

`str` реализует только сравнение на равенство (`==` / `!=`). Раньше сравнение строк операторами отношения **молча возвращало false**, теперь это ошибка компиляции.

- Допустимо: **односимвольный** строковый литерал `'a'`, неявно рассматриваемый как `char` (кодовая точка), который можно сравнивать с другим односимвольным литералом или с `char` (`"a"`). Числовые типы работают как обычно.
- Ошибка: многосимвольные строки — литерал `'ab'`, переменная `str` или вызов, возвращающий `str`.
- Для лексикографического сравнения используйте `str.compare(b)` (возвращает -1 / 0 / 1).

```nolang
'a' <= 'z'; true  — односимвольная строка неявно является char
ch >= 'a'; ch — char, допустимо
'a' > "b"; односимвольная строка против char, допустимо
'abc' < 'abd'; ошибка компиляции: многосимвольная строка
s1 < s2; ошибка компиляции: переменные str
s1.compare(s2) > 0; правильная запись
```
:::

## Логические операторы

- `&&` ; логическое И
- `||` ; логическое ИЛИ (также используется для объединения ветвей match, например `nil || err -> body`)
- `!` ; логическое НЕ

## Побитовые операторы

- `&` ; побитовое И
- `|` ; побитовое ИЛИ
- `^` ; побитовое исключающее ИЛИ
- `~` ; побитовое НЕ (инверсия)
- <code>&lt;&lt;</code> ; сдвиг влево
- `>>` ; сдвиг вправо

## Операторы присваивания

- `=` ; присваивание
- `+=` ; сложение с присваиванием
- `-=` ; вычитание с присваиванием
- `*=` ; умножение с присваиванием
- `/=` ; деление с присваиванием
- `%=` ; остаток с присваиванием
- `&=` ; побитовое И с присваиванием
- `|=` ; побитовое ИЛИ с присваиванием
- `^=` ; побитовое исключающее ИЛИ с присваиванием
- <code>&lt;&lt;=</code> ; сдвиг влево с присваиванием
- `>>=` ; сдвиг вправо с присваиванием

## Прочее

- `?` ; тернарный оператор (например, `c = flag ? 1 : 2`)
- `as` ; преобразование типа указателя FFI (например, `y = x as *byte`)
- `..` ; диапазон среза (например, `arr[1..3]`, `arr[1..]`, `arr[..3]`)
