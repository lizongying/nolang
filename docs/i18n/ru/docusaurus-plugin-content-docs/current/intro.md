# Введение в Nolang

Nolang — это экспериментальный системный язык программирования с безопасной работой с памятью без сборщика мусора, интуитивной семантикой и минималистичным синтаксисом.

## Ключевые возможности

- **Безопасность памяти**: без сборщика мусора; автоматическое управление памятью.
- **Высокая производительность**: оптимизация на этапе компиляции, без GC.
- **Минималистичный синтаксис**: меньше ключевых слов; никаких указателей, владения или времени жизни как скрытой умственной нагрузки; более простой синтаксис.
- **Ориентация на намерения**: уважает намерения разработчика; семантика соответствует человеческой интуиции.
- **Отсутствие сбоев**: устраняет скрытые пути привода к сбоям.

## Быстрый старт

```no
; Привет, мир!
; Точка входа main не требуется
print('Hello, Nolang!')

; Объявление переменной
count i64

; Определение функции
add = (a i64, b i64) (result i64) {
    result = a + b
}

; Метод стандартной библиотеки, можно вызывать напрямую
c = math.max(a, b)

; Структура
user {
    name str
    age i64
}

; Метод
user.greet = () {
    print('Hello, {.name}')
}

u = user {
    name: 'Alice'
    age: 30
}

u.greet()
```

## Примеры применения

- [notools](https://github.com/lizongying/notools) — набор распространённых инструментов командной строки Unix, реализованных на языке Nolang, включая классические утилиты cat, ls, grep, wc, head, tail и другие. Демонстрирует практические возможности Nolang в области системного программирования.
