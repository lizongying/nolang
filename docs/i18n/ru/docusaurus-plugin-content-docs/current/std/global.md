## Глобальные функции (Global)

### global — встроенные глобальные функции

Функции, которые можно вызывать без префикса модуля. Существует всего 7 глобальных функций; все остальные межмодульные вызовы требуют префикса модуля (например, `fs.read`, `os.get-env`):

```no
; Конструкторы ёмкости/длины (тип выводится из левой части присваивания)
s str = with-cap(256); предварительно выделить 256 байт для str (len=0)
v []i64 = with-cap(100); предварительно выделить срез на 100 элементов (len=0)
s str = with-len(10); str длиной 10
v []i64 = with-len(100); срез длиной 100
v []i64 = with-cap-len(200, 100); срез ёмкостью 200 и длиной 100

; также можно вызывать как методы str/vec:
s = ''.with-cap(256)
s = ''.with-len(10)
s = ''.with-len-cap(10, 256)
v = [].with-cap(100)
v = [].with-len(100)
v = [].with-len-cap(100, 200)

; Вывод/форматирование (именованные строки формата {name:spec})
print('x={x}'); именованный формат, stdout + перевод строки
eprint('err {x}'); именованный формат, stderr + перевод строки
s = format('x={x}'); возвращает отформатированную строку
print(a, b, c); несколько аргументов: разделены пробелами, один перевод строки в конце
print('result={val}', 42, 'result={val}'); при нескольких аргументах каждый литерал является шаблоном

; ({val} берётся из области видимости точки вызова, а не является строкой формата в стиле C)
;
; Полем может быть «переменная / путь к полю / метод без аргументов / индекс», и они могут объединяться по уровням:
print('{user.name} {user.name.len()} {tags[0]}')
print('{m[\'k\']} {m[\'k\'].len()}'); получение значения из map (в шаблоне экранируйте \' или пишите m["k"])

; Выполняется только «однократное снятие суффикса на каждом уровне»: методы с аргументами ({s.slice(0)}) и произвольные выражения ({a + 1}) не поддерживаются.

; Управление процессом
exit(0); завершить процесс с кодом состояния 0 (ранее os.exit, теперь глобальная функция)
```
