# Стандартная библиотека

Стандартная библиотека Nolang (`src/std/`) содержит более 80 модулей, охватывающих форматирование, математику, строки, структуры данных, кодирование/декодирование, шифрование, сжатие, работу с файлами, абстракции ввода-вывода, асинхронные сопрограммы, определение типов файлов и многое другое.

Использование: `# std/xxx` (базовые модули не требуют импорта).

> **Устаревший синтаксис `use std/xxx` всё ещё работает, но объявлен устаревшим (deprecated); рекомендуется новый синтаксис `# std/xxx`.**

> **Внимание: все примеры кода в этом документе соблюдают правило «одно выражение на строку» — использовать точки с запятой `;` или запятые `,` для записи нескольких выражений в одной строке запрещено.** Например, `out = from-i64(v), out = from-u64(v)` — неверная запись; её следует разбить на несколько строк.
