## Ядро библиотеки

### fmt — форматированный вывод

Nolang использует **именованные строки формата** `{name[:spec]}`, которые ссылаются на переменные из области видимости напрямую — без позиционных аргументов. Вывод идёт через системные вызовы `io.out`/`io.err` и не зависит от libc `printf`.

```no
print('x={x}'); именованный формат, автоматический перевод строки (stdout)
print('result={val}', 42, 'result={val}'); несколько аргументов: разделены пробелами; каждый литерал является отдельным шаблоном
eprint('err {x}'); именованный формат, автоматический перевод строки (stderr)
print('編號 {id:06} 金額 {money:.2f}'); поддержка выравнивания/заполнения/ширины/точности
s = format('x={x}'); возвращает отформатированную строку (заменяет sprintf)
io.out('no-newline-here'); низкоуровневая команда, вывод без перевода строки (stdout)
io.err('err-no-newline'); низкоуровневая команда, вывод без перевода строки (stderr)
; printf/eprintf удалены (вызов — ошибка компиляции [printf-depr]): printf→print/io.out, eprintf→eprint/io.err
; sprintf всё ещё работает, но объявлен устаревшим: sprintf→format
; io.err несёт явный префикс модуля и не конфлирует с конструктором Option err()
```

### math — математические функции (API в функциональной форме)

Все численные API.std в «функциональной форме» собраны в модуле math (std/math.no); все API в «форме методов» (`*.to-str`, f64/f32 sqrt/sin/exp…, целочисленные sqrt/is-prime) находятся в модуле number (см. раздел number ниже). Объединённые типы и их методы-члены: num → std/num.no, int → std/int.no, float → std/float.no.

**Константы:** `math.PI`, `math.E`, `math.LN10` (ln 10, в паре с f64-to-str)

**Сравнение (числовые обобщённые вариадические функции):** `math.max`, `math.min` (`a ..num`, целые и числа с плавающей точкой идут по одному пути мономорфизации)

**Степень/корень (функции):** `math.pow` (возведение f64 в степень a^b, реализация чистая на .no: `exp(y*ln|x|)` плюс обработка знака отрицательного основания (при нечётном целом показателе знак сохраняется, при чётном — отбрасывается, при нецелом возвращается NaN), **без зависимости от libm**), `math.hypot` (sqrt(x*x+y*y))

**Прочие функции:** `math.atan2`, `math.fmod` (остаток от деления с плавающей точкой), `math.clamp` (насыщающее ограничение i64)

**Целочисленная математика (обобщённые int-функции):** `math.even`, `math.odd`, `math.gcd`, `math.lcm`, `math.div` (частное), `math.mod` (остаток)

**Преобразование типов (старые функциональные формы `math.i64-to-f64` / `math.f64-to-i64` / `math.f32-to-f64` / `math.f64-to-f32` удалены, используйте форму методов):** `v.to-f64()`、`v.to-i64()`、`f32.to-f64()` / `f64.to-f32()` (модуль number; у всех целочисленных ширин есть `.to-f64()`, в том числе i128 / u128)

**Низкоуровневое преобразование числа в строку:** осталась только `math.char-to-str` (устарела, рекомендуется `c.to-str()`); `math.i64-to-str` / `math.u64-to-str` / `math.f64-to-str` удалены — используйте форму методов `v.to-str()`

**Побитовые операции (функции):** `math.swap`, `math.arr-zero`, `math.rotate-left`, `math.rotate-right`, `math.store-le-u32`

> Целочисленная степень: `math.pow-int` (обобщённое int-быстрое возведение в степень, выделено в отдельный модуль, отлично от `math.pow` для f64); `number.pow` сохраняет явную сигнатуру i64 ради исторических проверок.

### number — численные операции (API в форме методов)

Численные API.std в «форме методов» собраны в модуле number (std/number.no); функциональные API — в разделе math выше. Объединённые типы int / float / num описаны в своих разделах.

**Константы диапазона:** i8.MIN / MAX … i128.MIN / MAX, u8.MIN / MAX … u128.MAX; `number.INF`

**Целочисленная степень (функция):** `r = number.pow(base, n)` (base^n, n ≥ 0, быстрое возведение O(log n), сигнатура i64, при переполнении происходит циклический переход; обобщённая int-версия — `math.pow-int` выше)

**Целочисленные методы:** `n.sqrt()` (целочисленный квадратный корень floor(√n), для отрицательных возвращает 0), `n.is-prime()` (проверка на простоту) — доступны версии для ширин i8 / i16 / i32 / i64 / u8 / u16 / u32 / u64, а также версии для i128 / u128 (128-битная арифметика идёт через LLVM i128 и работоспособна; требуется явно аннотировать локальную переменную, например `n i128 = .`, и правильно расположить аннотацию `#{overflow=wrap}` в соответствии со знаковостью)

**to-str для конкретных типов (методы):** `v.to-str()` — для ширин i8 / i16 / i32 / i64 / u8 / u16 / u32 / u64 / byte / f32 / f64; поддерживаются также i128 / u128 (через нативные `@str_from_i128` / `@str_from_u128`)

**Методы чисел с плавающей точкой (f64 и одноимённые f32):** тригонометрия `x.sin()`, `x.cos()`, `x.tan()`, `x.asin()`, `x.acos()`, `x.atan()`; гиперболические `x.sinh()`, `x.cosh()`, `x.tanh()`; округление `x.ceil()`, `x.floor()`, `x.round()`, `x.trunc()`; экспонента/логарифм `x.exp()`, `x.log()`, `x.log10()`, `x.log2()`; степень/корень `x.sqrt()`, `x.cbrt()`; градусы/радианы `x.degrees()`, `x.radians()`. Внутри f32 вычисляется с точностью double, затем результат сужается до f32.

### char — работа с символами

char по сути является i32 (кодовая точка Unicode), все операции предоставляются в форме методов:

```no
c char = 'A'
c.is-digit(); является ли цифрой (0-9) (метод)
c.is-letter(); является ли буквой (a-z, A-Z) (метод)
c.is-alpha(); псевдоним is-letter (метод)
c.is-alnum(); является ли буквой или цифрой (метод)
c.is-space(); является ли пробельным символом (метод)
c.is-upper(); является ли заглавной буквой (метод)
c.is-lower(); является ли строчной буквой (метод)
c.to-upper(); перевести в верхний регистр (ASCII) (метод)
c.to-lower(); перевести в нижний регистр (ASCII) (метод)
c.to-bytes(); Unicode → байты UTF-8 (метод)
c.to-str(); Unicode → строка (UTF-8, метод)
```

### str — работа со строками

Дескриптор `str` — это `{ u32 len, u32 cap, i8* data }` (16 байт на 64-битной системе), но параметры и возвращаемые значения `s.len()` / `s.len-bytes()` / `s.cap()`, а также `with-cap` / `with-len` / `with-cap-len` **по-прежнему все имеют тип `i64`**: преобразование u32 ↔ i64 выполняется компилятором на границе дескриптора. Подробнее см. [Строки: внутреннее представление и публичный API](../lang/str.md). На `txt` это изменение не влияет.

Дескриптор среза `[]t` устроен аналогично: `%vec = { u32 len, u32 cap, i64 data }` (16 байт, `data` — указатель в кодировке `ptrtoint`), и `v.len()` тоже остаётся `i64`. У `[n]t` нет дескриптора времени выполнения (элементы встроены в `[n x t]`, `.len` — константа времени компиляции).

```no
#{fmt-skip}
ok = a.eq(b, n)               ; сравнение на равенство (метод)
dst = s.copy()                ; копирование строки (метод)
s.fill(val byte)              ; заполнение значением byte (метод)
pos = s.index(sub)            ; позиция подстроки
ok = s.contains(sub)          ; содержит ли
ok = s.starts-with(sub)       ; проверка префикса
ok = s.ends-with(sub)         ; проверка суффикса
s.to-upper()                  ; перевести в верхний регистр
s.to-lower()                  ; перевести в нижний регистр
out = s.trim()                ; удалить начальные и конечные пробелы
out = s.repeat(n)             ; повторить
out = s.slice(start, end)     ; срез (индексы — позиции кодовых точек)
b = s.to-bytes()              ; преобразовать в []byte
s = b.to-str()                ; []byte в str (метод)
v = s.to-i64()                ; строка в i64 (возвращает ?i64)
v = s.to-i8()                 ; строка в i8 (возвращает ?i8)
v = s.to-i16()                ; строка в i16 (возвращает ?i16)
v = s.to-i32()                ; строка в i32 (возвращает ?i32)
v = s.to-u8()                 ; строка в u8 (возвращает ?u8)
v = s.to-u16()                ; строка в u16 (возвращает ?u16)
v = s.to-u32()                ; строка в u32 (возвращает ?u32)
v = s.to-u64()                ; строка в u64 (возвращает ?u64)
v = s.to-byte()               ; строка в byte (возвращает ?byte)
v = s.to-f64()                ; строка в f64 (возвращает ?f64)
v = s.to-bool()               ; строка "true"/"false" в bool (возвращает ?bool)
s = v.to-str()                ; i64 в строку (метод)
out = s.reverse()             ; обратить
c = s.compare(b)              ; лексикографическое сравнение
n = s.count()                 ; общее число кодовых точек
val = s.replace-char(old, new) ; замена символа (возвращает строку-результат)
out = s.trim-char(c)          ; удалить указанный символ
ok = s.empty()                ; пуста ли
s.clear()                     ; очистить (len=0, изменение на месте)
s = with-cap(cap)            ; встроенный синтаксис: создать новую строку заданной ёмкости (len=0)
s = with-len(len)            ; встроенный синтаксис: создать строку заданной длины (len=cap)
s = with-cap-len(cap, len)   ; встроенный синтаксис: создать строку заданной ёмкости и длины
parts = s.split(sep)          ; разделить по разделителю (возвращает []str, метод)
out = ss.join(sep)            ; объединить []str с разделителем (метод)
```

### num — объединённый тип num и методы num

`num = int | float` (std/num.no). Методы типа num находятся в модуле num (обобщённые функции max/min — в разделе math выше):

```no
r = num.abs(); абсолютное значение (метод)
r = num.clamp(lo, hi); ограничение диапазоном (метод)
r = num.sign(); знак (-1/0/1, метод)
```

### int — объединённый тип int и методы int

`int = i8 | i16 | i32 | i64 | i128 | u8 | u16 | u32 | u64 | u128` (std/int.no). Методы типа int находятся в модуле int:

```no
s = v.to-str(); целое в строку (метод)
q = v.div(b); деление с получением частного (возвращает option)
r = v.mod(b); остаток (возвращает option)
```

### float — объединённый тип float и методы float

`float = f32 | f64` (std/float.no). Методы типа float находятся в модуле float:

```no
q = v.div(b); деление с плавающей точкой
yes = v.is-nan(); проверка на NaN (метод)
yes = v.is-inf(); проверка на Inf (метод)
```

(Объединённый метод float.to-str не определяется; переменные f64/f32 напрямую используют метод конкретного типа `v.to-str()`.)

### number — примеры использования методов

(Полный API — в разделе «number — численные операции (API в форме методов)» выше; функциональная форма — в разделе «math».)

```no
; форма методов (модуль number)
s = v.to-str(); целое/число с плавающей точкой в строку (все ширины)

; функциональная форма (модуль math)

l = math.lcm(a, b); наименьшее общее кратное

sw = math.swap(a, b); обмен

; числовые преобразования (форма методов, старые функции math.*-to-* удалены)

n = x.to-i64(); f64 → целое (усечение)
w = f32v.to-f64(); f32 → f64; обратно f64.to-f32()

; константы диапазона (модуль number)
i8.MIN / MAX; -128 / 127
i16.MIN / MAX; -32768 / 32767
i32.MIN / MAX; -2147483648 / 2147483647
i64.MIN / MAX; -2^63 / 2^63-1
i128.MIN / MAX; -2^127 / 2^127-1
u8.MIN / MAX; 0 / 255
u16.MIN / MAX; 0 / 65535
u32.MIN / MAX; 0 / 4294967295
u64.MIN / MAX; 0 / 2^64-1
u128.MIN / MAX; 0 / 2^128-1
```

### txt — текстовый тип фиксированной длины

`txt` — текстовый тип фиксированного размера 256 байт, подходит для коротких строк:
- первые 255 байт хранят данные (`data [255]byte`)
- последний 1 байт хранит длину (`len byte`, единица измерения — «байты», диапазон 0-255)
- выделение в куче не требуется, всё находится в стеке
- необходимо указание типа

Семантика длины (согласована со `str`):
- `t.len()` → число символов (кодовых точек) (эквивалентно `t.count()`)
- `t.len-bytes()` → число байт (фактическая длина базового буфера UTF-8)
- индексация / срезы / добавление и другие побайтовые операции ориентируются на `len-bytes()`; для ASCII оба значения равны, а при наличии многобайтовых UTF-8 `len() < len-bytes()`

```no
#{fmt-skip}
t txt = 'hello'              ; необходимо указание типа
n = t.len()                  ; число символов (кодовых точек) (i64)
b = t.len-bytes()            ; число байт (i64)
c = t[0]                     ; индексный доступ (byte)
ok = t.eq(b txt)             ; сравнение на равенство
dst = t.copy()               ; копирование
s = t.to-str()              ; преобразование в str
out = t.to-bytes()           ; преобразование в []byte
pos = t.index(sub txt)       ; поиск подстроки
ok = t.contains(sub txt)     ; содержит ли
ok = t.starts-with(sub txt)  ; проверка префикса
ok = t.ends-with(sub txt)    ; проверка суффикса
t.push(c char)              ; добавить одну кодовую точку (если весь символ не помещается в лимит 255, игнорируется вся операция)
t.push-str(s str)            ; добавить str (усечение по байтам до 255)
t.push-txt(t2 txt)           ; добавить txt (усечение по байтам до 255)
out = t.reverse()            ; обратить
out = t.slice(start, end)   ; вырезать [start, end)
r = t.compare(b txt)        ; лексикографическое сравнение (-1/0/1)
```

### vec — работа со срезами

```no
#{fmt-skip}
v = vec.vec-create(n, val)         ; создать срез длиной n, заполнить все val
ok = []t.eq(a, b, n)           ; сравнение на равенство

[]t.push(val)                   ; добавить (автоматическое расширение)

v = with-cap(cap)             ; встроенный синтаксис: создать новый срез заданной ёмкости (len=0)
v = with-len(len)             ; встроенный синтаксис: создать срез заданной длины (len=cap)
v = with-cap-len(cap, len)    ; встроенный синтаксис: создать срез заданной ёмкости и длины
val, new-n = []t.pop()         ; взять последний элемент
found = []t.contains(n, val)   ; содержит ли (n — длина)
[]t.reverse(n)                  ; обратить первые n элементов
[]t.clone(dst)                  ; скопировать в dst
[]t.fill(n, val)                ; заполнить первые n элементов
arr = []t.to-arr()             ; преобразовать в массив
[]t.sort-asc()                  ; сортировка по возрастанию (метод)
[]t.sort-desc()                 ; сортировка по убыванию (метод)
```
