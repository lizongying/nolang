# 標準ライブラリ

Nolang 標準ライブラリ（`src/std/`）は 80 個以上のモジュールを含み、フォーマット、数学、文字列、データ構造、エンコード／デコード、暗号化、圧縮、ファイル操作、I/O 抽象、非同期コルーチン、ファイル種別検出などをカバーしています。

使い方：`# std/xxx`（コアモジュールはインポート不要です）。

> **旧式の `use std/xxx` も引き続き使用できますが、非推奨（deprecated）です。新しい構文 `# std/xxx` の使用をお勧めします。**

> **注意：本文書のコード例はすべて「1 行に 1 文」の規則に従っています。セミコロン `;` やカンマ `,` を使って複数の文を同じ行に記述することは禁止されています。** たとえば `out = from-i64(v), out = from-u64(v)` は誤った書き方であり、複数行に分割する必要があります。
