# 演算子

## 特殊記号

- `#` ; モジュールを導入する
- `@` ; モジュールをエクスポートする
- `->` ; match アームと if/else の分岐（例：`cond -> body`）
- `:` ; match 式（例：`x: { ... }`）
- `{ } (true)` ; 無限ループ（後置形式、旧式の書き方）。前置形式の `!! { }` / `true { }` は同義で、新しいデフォルトです（`no fmt` の出力）
- `<-` ; 範囲の走査（例：`i <- [a..b]: { }`）
- `..` ; 親クラス／範囲演算子（例：`[a..b)`）
- `.` ; クラス自身（⚠️ 範囲の上限では、3 点が連続する視覚的な曖昧さを避けるため `.method` ではなく `self.method` を使ってください）
- `?` ; option 型のプレフィックス（例：`?i64`、`?str`）
- `(cond) { }` ; 条件ループ（前置形式、新しいデフォルト。後置形式 `{ } (cond)` と等価）
- `N * { }` ; 回数指定ループ（前置形式、新しいデフォルト。後置形式 `{ } * N` と等価。N ≤ 0 の場合はスキップ）
- `!` ; 偽（false）。また「実行しない」ループのプレフィックスでもあります（`! { }` は決して実行されません）
- `!!` ; 真（true）。また「常に実行する」ループのプレフィックスでもあります（`!! { }` は無限ループ）
- `{ } ()` ; 実行しない（空のかっこは false を表します。後置形式、旧式の書き方）。前置形式の `! { }` / `false { }` / `() { }` は同義で、新しいデフォルトです
- `*` ; 現在の繰り返しをスキップする（continue の代替。parser は受け付けますが、現時点では推奨しません。キーワードを使ってください）
- `**` ; 中断する（break の代替。parser は受け付けますが、現時点では推奨しません。キーワードを使ってください）
- `***` ; リターン文、関数を終了する（return の代替。計画中で、現時点では推奨しません。キーワードを使ってください）
- `awy { }` ; コルーチングループ。グループの末尾ですべての `co` タスクをまとめて待ちます
- `co` ; カラーレスな async の派生。`awy { }` グループ内でのみ合法です

## 算術演算子

- `+` ; 加算
- `-` ; 減算（文字列の連結にも使えます）
- `*` ; 乗算（文字列の繰り返しにも使えます）
- `/` ; 除算

## 比較演算子

- `==` ; 等しい（`str` は実際の文字列の等価比較を持ち、複数文字も合法です）
- `!=` ; 等しくない（同上）
- <code>&lt;</code> ; より小さい
- `>` ; より大きい
- <code>&lt;=</code> ; 以下
- `>=` ; 以上

:::warning 関係演算子（<code>&lt;</code> `>` <code>&lt;=</code> `>=`）には文字列の辞書順の意味はありません

`str` は等価比較（`==` / `!=`）のみを持ちます。文字列に対して関係演算を行うと、以前は**暗黙的に false を返していました**が、現在はコンパイルエラーです。

- 合法：**1 文字**の文字列リテラル `'a'` は暗黙的に `char`（コードポイント）として扱われ、別の 1 文字リテラルや `char`（`"a"`）と比較できます。数値型は通常どおりです。
- エラー：複数文字の文字列——複数文字のリテラル `'ab'`、`str` 変数、`str` を返す呼び出し。
- 辞書順での比較が必要な場合は `str.compare(b)` を使ってください（-1 / 0 / 1 を返します）。

```nolang
'a' <= 'z'; true  — 單字元字串隱式 char
ch >= 'a'; ch 為 char，OK
'a' > "b"; 單字元字串 vs char，OK
'abc' < 'abd'; 編譯錯誤：多字元字串
s1 < s2; 編譯錯誤：str 變數
s1.compare(s2) > 0; 正確寫法
```
:::

## 論理演算子

- `&&` ; 論理積
- `||` ; 論理和（match の分岐の組み合わせにも使えます。例：`nil || err -> body`）
- `!` ; 論理否定

## ビット演算子

- `&` ; ビットごとの AND
- `|` ; ビットごとの OR
- `^` ; ビットごとの XOR
- `~` ; ビットごとの NOT
- <code>&lt;&lt;</code> ; 左シフト
- `>>` ; 右シフト

## 代入演算子

- `=` ; 代入
- `+=` ; 加算代入
- `-=` ; 減算代入
- `*=` ; 乗算代入
- `/=` ; 除算代入
- `%=` ; 剰余代入
- `&=` ; ビット AND 代入
- `|=` ; ビット OR 代入
- `^=` ; ビット XOR 代入
- <code>&lt;&lt;=</code> ; 左シフト代入
- `>>=` ; 右シフト代入

## その他

- `?` ; 三項演算子（例：`c = flag ? 1 : 2`）
- `as` ; FFI ポインタ型の変換（例：`y = x as *byte`）
- `..` ; スライスの範囲（例：`arr[1..3]`、`arr[1..]`、`arr[..3]`）
