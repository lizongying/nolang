# 运算符

## 特殊符号

- `#` ; 引入模块
- `@` ; 导出模块
- `->` ; match arm 与 if/else 分支（如 `cond -> body`）
- `:` ; match 表达式（如 `x: { ... }`）
- `{ } (true)` ; 无限循环（后缀式，旧式写法）；前置式 `!! { }` / `true { }` 同义，为新式预设（`no fmt` 输出）
- `<-` ; 范围遍历（如 `i <- [a..b]: { }`）
- `..` ; 父类 / 范围运算子（如 `[a..b)`）
- `.` ; 类自身（⚠️ 在区间上界中，应使用 `self.method` 而非 `.method`，避免三点连写的视觉歧义）
- `?` ; option 类型前缀（如 `?i64`、`?str`）
- `(cond) { }` ; 条件循环（前置式，新式预设，等同后缀式 `{ } (cond)`）
- `N * { }` ; 计数循环（前置式，新式预设，等同后缀式 `{ } * N`，N ≤ 0 跳过）
- `!` ; 假（false）；也是「不执行」循环前缀（`! { }` 永不执行）
- `!!` ; 真（true）；也是「恒执行」循环前缀（`!! { }` 无限循环）
- `{ } ()` ; 不执行（空括号代表 false；后缀式，旧式写法）；前置式 `! { }` / `false { }` / `() { }` 同义，为新式预设
- `*` ; 跳过本轮 替代continue（ parser 已接受，但暂不推荐使用，请用关键字）
- `**` ; 中断 替代break（parser 已接受，但暂不推荐使用，请用关键字）
- `***` ; 返回语句，终止函数 替代return（规划中，暂不推荐使用，请用关键字）
- `awy { }` ; 协程组，组尾统一等待所有 `co` 任务
- `co` ; 无色 async 衍生，仅在 `awy { }` 组内合法

## 算术运算符

- `+` ; 加法
- `-` ; 减法（也可用于字串拼接）
- `*` ; 乘法（也可用于字串重复）
- `/` ; 除法

## 比较运算符

- `==` ; 等于（`str` 有真正的字串相等比较，多字元合法）
- `!=` ; 不等于（同上）
- <code>&lt;</code> ; 小于
- `>` ; 大于
- <code>&lt;=</code> ; 小于等于
- `>=` ; 大于等于

:::warning 关系运算子（<code>&lt;</code> `>` <code>&lt;=</code> `>=`）没有字串字典序语意

`str` 只有相等比较（`==` / `!=`）；对字串做关系运算过去会**静默回传 false**，现在是编译错误。

- 合法：**单字元**字串字面量 `'a'`，隐式视为 `char`（码点），可与另一个单字元字面量或 `char`（`"a"`）比较。数值型别照常。
- 错误：多字元字串 —— 多字元字面量 `'ab'`、`str` 变数、回传 `str` 的呼叫。
- 需要字典序比较时用 `str.compare(b)`（回传 -1 / 0 / 1）。

```nolang
'a' <= 'z'; true  — 单字元字串隐式 char
ch >= 'a'; ch 为 char，OK
'a' > "b"; 单字元字串 vs char，OK
'abc' < 'abd'; 编译错误：多字元字串
s1 < s2; 编译错误：str 变数
s1.compare(s2) > 0; 正确写法
```
:::

## 逻辑运算符

- `&&` ; 逻辑与
- `||` ; 逻辑或（也可用于 match 分支组合，如 `nil || err -> body`）
- `!` ; 逻辑非

## 位运算符

- `&` ; 按位与
- `|` ; 按位或
- `^` ; 按位异或
- `~` ; 按位取反
- <code>&lt;&lt;</code> ; 左移
- `>>` ; 右移

## 赋值运算符

- `=` ; 赋值
- `+=` ; 加赋值
- `-=` ; 减赋值
- `*=` ; 乘赋值
- `/=` ; 除赋值
- `%=` ; 模赋值
- `&=` ; 位与赋值
- `|=` ; 位或赋值
- `^=` ; 位异或赋值
- <code>&lt;&lt;=</code> ; 左移赋值
- `>>=` ; 右移赋值

## 其他

- `?` ; 三元运算符（如 `c = flag ? 1 : 2`）
- `as` ; FFI 指标型别转换（如 `y = x as *byte`）
- `..` ; 切片范围（如 `arr[1..3]`、`arr[1..]`、`arr[..3]`）
