# 연산자

## 특수 기호

- `#` ; 모듈 가져오기
- `@` ; 모듈 내보내기
- `->` ; match arm 및 if/else 분기(예: `cond -> body`)
- `:` ; match 표현식(예: `x: { ... }`)
- `{ } (true)` ; 무한 반복문(후위형, 구식 표기). 전위형 `!! { }` / `true { }`와 동의어이며 새로운 기본형(`no fmt` 출력)
- `<-` ; 범위 순회(예: `i <- [a..b]: { }`)
- `..` ; 상위 클래스 / 범위 연산자(예: `[a..b)`)
- `.` ; 클래스 자신(⚠️ 구간 상한에서는 세 점이 연속되는 시각적 모호성을 피하기 위해 `.method` 대신 `self.method`를 사용해야 합니다)
- `?` ; option 타입 접두사(예: `?i64`, `?str`)
- `(cond) { }` ; 조건 반복문(전위형, 새로운 기본형, 후위형 `{ } (cond)`와 동일)
- `N * { }` ; 횟수 반복문(전위형, 새로운 기본형, 후위형 `{ } * N`과 동일, N ≤ 0이면 건너뜀)
- `!` ; 거짓(false); "실행하지 않음" 반복문 접두사이기도 함(`! { }`는 절대 실행되지 않음)
- `!!` ; 참(true); "항상 실행" 반복문 접두사이기도 함(`!! { }`는 무한 반복)
- `{ } ()` ; 실행하지 않음(빈 괄호는 false를 뜻함; 후위형, 구식 표기). 전위형 `! { }` / `false { }` / `() { }`와 동의어이며 새로운 기본형
- `*` ; 현재 반복 건너뛰기, continue 대체(parser가 이미 허용하지만 사용을 권장하지 않음. 키워드를 사용하세요)
- `**` ; 중단, break 대체(parser가 이미 허용하지만 사용을 권장하지 않음. 키워드를 사용하세요)
- `***` ; 반환 문장, 함수 종료, return 대체(계획 중이며 사용을 권장하지 않음. 키워드를 사용하세요)
- `awy { }` ; 코루틴 그룹, 그룹 끝에서 모든 `co` 작업을 한꺼번에 대기
- `co` ; 색이 없는 async 파생, `awy { }` 그룹 내부에서만 합법

## 산술 연산자

- `+` ; 덧셈
- `-` ; 뺄셈(문자열 연결에도 사용 가능)
- `*` ; 곱셈(문자열 반복에도 사용 가능)
- `/` ; 나눗셈

## 비교 연산자

- `==` ; 같음(`str`에 실제 문자열 동등 비교가 있으며 여러 문자도 허용)
- `!=` ; 같지 않음(위와 동일)
- <code>&lt;</code> ; 미만
- `>` ; 초과
- <code>&lt;=</code> ; 이하
- `>=` ; 이상

:::warning 관계 연산자(<code>&lt;</code> `>` <code>&lt;=</code> `>=`)에는 문자열 사전순 의미가 없습니다

`str`에는 동등 비교(`==` / `!=`)만 있습니다. 문자열에 관계 연산을 수행하면 과거에는 **조용히 false를 반환**했지만 지금은 컴파일 오류입니다.

- 허용: **한 문자** 문자열 리터럴 `'a'`는 암시적으로 `char`(코드 포인트)로 간주되어 다른 한 문자 리터럴이나 `char`(`"a"`)와 비교할 수 있습니다. 숫자 타입은 평소와 같습니다.
- 오류: 여러 문자로 된 문자열 — 여러 문자 리터럴 `'ab'`, `str` 변수, `str`을 반환하는 호출.
- 사전순 비교가 필요하면 `str.compare(b)`를 사용하세요(-1 / 0 / 1 반환).

```nolang
'a' <= 'z'; true  — 單字元字串隱式 char
ch >= 'a'; ch 為 char，OK
'a' > "b"; 單字元字串 vs char，OK
'abc' < 'abd'; 編譯錯誤：多字元字串
s1 < s2; 編譯錯誤：str 變數
s1.compare(s2) > 0; 正確寫法
```
:::

## 논리 연산자

- `&&` ; 논리곱
- `||` ; 논리합(match 분기 조합에도 사용 가능, 예: `nil || err -> body`)
- `!` ; 논리 부정

## 비트 연산자

- `&` ; 비트 AND
- `|` ; 비트 OR
- `^` ; 비트 XOR
- `~` ; 비트 NOT
- <code>&lt;&lt;</code> ; 왼쪽 시프트
- `>>` ; 오른쪽 시프트

## 대입 연산자

- `=` ; 대입
- `+=` ; 더하기 대입
- `-=` ; 빼기 대입
- `*=` ; 곱하기 대입
- `/=` ; 나누기 대입
- `%=` ; 나머지 대입
- `&=` ; 비트 AND 대입
- `|=` ; 비트 OR 대입
- `^=` ; 비트 XOR 대입
- <code>&lt;&lt;=</code> ; 왼쪽 시프트 대입
- `>>=` ; 오른쪽 시프트 대입

## 기타

- `?` ; 삼항 연산자(예: `c = flag ? 1 : 2`)
- `as` ; FFI 포인터 타입 변환(예: `y = x as *byte`)
- `..` ; 슬라이스 범위(예: `arr[1..3]`, `arr[1..]`, `arr[..3]`)
